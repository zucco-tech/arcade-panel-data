# Les journaux

La sortie brute de chaque balayage, conservée telle quelle.

`2026-09-11-fbneo.log` — le premier, sur une borne Recalbox équipée d'une
carte AllInOne, Raspberry Pi 5 :

```
1903 jeux parcourus
1617 adresses trouvees
 286 ecartes
   0 echec technique
en 9 h 15
```

On y voit chaque jeu, le nombre de candidats après chaque pièce, et pourquoi
un jeu a été écarté. C'est ce qui permet de refaire le chemin — ou de
comprendre, dans six mois, pourquoi tel jeu manque.
